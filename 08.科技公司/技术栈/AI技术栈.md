# AI技术栈

## LLM API

| 服务 | 说明 | 适用场景 |
|------|------|---------|
| OpenAI GPT | 通用大模型 | 对话、文案、代码 |
| Claude (Anthropic) | 长文本、深度分析 | 长文档处理 |
| 通义千问 | 国产大模型 | 中文场景 |
| 文心一言 | 百度大模型 | 国内合规 |

## 开发框架

| 框架 | 说明 | 特点 |
|------|------|------|
| LangChain | LLM应用框架 | 灵活、生态大 |
| LlamaIndex | 数据索引框架 | 知识库检索强 |
| Dify | 可视化智能体平台 | 开箱即用 |
| Coze | 智能体搭建平台 | 快速部署 |

## 向量数据库

| 数据库 | 特点 |
|--------|------|
| Chroma | 轻量、Python友好 |
| Milvus | 高性能、大规模 |
| Pinecone | 托管服务 |
| pgvector | PostgreSQL扩展 |
