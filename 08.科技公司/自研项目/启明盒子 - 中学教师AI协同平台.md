# 启明盒子 - 中学教师AI协同平台

> 状态：讨论阶段 | 定位：中小学教育 AI 协同平台
> 日期：2026-03-10

---

## 一、项目摘要

**「启明盒子」** 是一款专为中国中小学教师设计的 AI 协同平台，核心理念"赋能而非替代"。

- **核心架构**：多智能体协同，中央调度大脑「明睿」+ 八大中华传统智慧命名智能体
- **覆盖场景**：备课、授课、作业、评价、班级管理、教研、家校沟通
- **核心价值**：一个平台，解决教师所有烦恼

---

## 二、需求分析

### 教师真实痛点

| 痛点 | 数据 |
|------|------|
| 备课耗时 | 初中教师平均每周 16.8 小时，资源筛选占 5.2 小时 |
| 作业负担 | 语文教师批改作文 2.5 分钟/篇，50 人班级需 2 小时 |
| 学情模糊 | 65% 班主任难以全面掌握学生心理状态 |
| AI 冲击 | 89% 教师遇过学生用 AI 完成作业，仅 12% 有应对方法 |
| 管理琐碎 | 班主任日均处理家校沟通等事务 1.5 小时 |
| 发展受限 | 72% 教师希望有工具帮助整理教学成果用于职称评定 |

### 政策机遇
- 教育数字化战略行动（2023）
- 双减政策
- 新课标核心素养落地
- 教师减负清单

### 市场空白
- 学生端 AI 搜题（作业帮）：直接给答案，缺乏教育引导
- 通用大模型（ChatGPT）：内容不可控，缺乏教育专业性
- 教师工具类 App（班级优化大师）：功能单一，数据孤岛

## 三、系统架构

### 总体架构层级

```
用户层 → 接入层 → 核心服务层 → 数据层 → 基础设施层
```

| 层级 | 核心组件 | 技术选型 |
|------|----------|----------|
| **用户层** | 教师端、学生端、管理者端、家长端 | Vue3/React/微信小程序/Flutter |
| **接入层** | 统一身份认证、API网关、负载均衡 | Keycloak/Kong/Nginx+LVS |
| **核心服务层** | 中央调度大脑、八大智能体、知识库引擎 | Python/Go 微服务、Milvus/Neo4j |
| **数据层** | MySQL集群、Milvus向量库、MinIO对象存储 | Redis集群、ClickHouse、ES |
| **基础设施层** | 混合云、CDN、安全防护 | 华为云/阿里云、WAF、DDoS高防 |

### 多端覆盖

| 终端 | 技术 | 功能 |
|------|------|------|
| 教师端 | Vue3/React + 微信小程序 | PC备课、手机处理事务 |

## 四、八大智能体

### 1. 「明睿」中央调度大脑
- **职责**：意图识别、任务规划、智能体调度、结果聚合
- **技术**：大模型微调（BERT）、意图分类、任务规划算法
- **输入**：教师自然语言指令（文本/语音）
- **输出**：结构化响应

### 2. 「匠心」教学设计智能体
- **职责**：生成教案（三维目标/重难点/教学过程/板书设计）
- **特性**：跨学科链接建议、分层任务设计、学情联动
- **输出**：Word/PPT 格式教案

### 3. 「问渠」学生互动智能体
- **职责**：多轮引导式对话，不直接给答案
- **技术**：多模态识别（OCR/语音）、引导式对话策略、情感分析
- **特性**：晚10点至早6点禁用（未成年人保护）

### 4. 「明鉴」内容溯源智能体
- **职责**：事实交叉验证、强制溯源、AI生成内容检测、敏感内容过滤
- **技术**：信息检索、可信度评估、AI文本检测（困惑度分析）

### 5. 「明心」学业心理分析智能体
- **职责**：学业诊断、心理分析（NLP情感分析）、行为预警、综合素质评价
- **输出**：可视化报告（雷达图/趋势图/预警名单）
- **技术**：知识图谱、NLP情感分析、关联规则挖掘

### 6. 「乐学」作业测评智能体
- **职责**：智能组卷、分层作业、作文初评
- **技术**：智能组卷算法、文本纠错、语句通顺度评估
- **数据源**：学科网、中学学科网

### 7. 「仁辅」班级管理智能体
- **职责**：通知生成、班会设计、家校沟通策略
- **输出**：多风格文案（家长微信群版/校讯通版/学生版）

### 8. 「致远」教师发展智能体
- **职责**：教学日志整理、文献检索、论文框架生成、课题申报书
- **数据源**：知网、万方等学术数据库

### + 「善治」教务管理智能体
- **职责**：排课/调课、实验室预约、物资管理
- **技术**：约束满足算法、资源调度优化

## 五、典型工作流

### 场景一：教师备课（跨学科+学情联动）
1. 教师输入自然语言指令 → API网关 → 中央调度大脑
2. 明睿解析意图 → 调用明心（学情）+ 匠心（教案）
3. 明心从数据中台读取成绩数据 → 生成学情摘要
4. 匠心从知识库检索教材/课标/优秀教案 → 生成分层教案
5. 聚合结果 → 返回教师端（教案+学情提醒+跨学科建议）

### 场景二：班主任处理班级问题
- 系统主动推送异常报告（宿舍卫生+心理预警）
- 调用明心深度分析 + 仁辅生成班会方案
- 结合真实情况生成针对性策划案

### 场景三：学生提问（引导式学习）
- 学生拍照上传题目 → OCR识别
- 引导式对话：分步引导，学生自己得出答案
- 记录学习行为，更新知识图谱

## 六、数据安全与隐私

### 合规框架
- 《个人信息保护法》《未成年人保护法》《数据安全法》
- 数据四级分类：L1公开 → L2内部 → L3敏感 → L4极敏感（不收集）

### 技术措施
- 传输加密：TLS 1.3
- 存储加密：AES-256
- RBAC 访问控制 + 最小权限原则
- 审计日志保存 6 个月
- 匿名化处理（心理预警报告默认使用化名）

### 伦理保障
- 人工审核回路：AI 只提供建议，最终判断权在老师手中
- 知情同意：入学时签署数字服务同意书
- 未成年人保护：学生端晚10点至早6点禁用
