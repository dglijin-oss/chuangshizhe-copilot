# IP 内容策划工作台 - 产品需求文档

> 复刻目标：127.0.0.1:5173 上的完整网站

---

## 产品概述

| 项目 | 内容 |
|------|------|
| 产品名称 | 广西流量终结者 · IP Content Workspace |
| 核心价值 | 从单条爆款生成器升级为整个账号的周策划工作台 |
| 核心理念 | 先建一个 IP，再策划它整周发什么 |
| 技术 | AI 驱动，基于 IP 档案知识库生成周选题池 |
| 当前阶段 | Web 测试版（localhost:5173） |

---

## 完整用户流程

```
首页 Dashboard
    │
    ▼
点击"创建新策划方案"
    │
    ▼
方法论引导页（API 授权 + 三步说明）
    │
    ▼
创建 IP 档案表单（多屏滚动）
    ├── 3A: 基础信息（IP名、创始人、人设）
    ├── 3B: 行业 + 产品/服务
    ├── 3C: 目标客户
    ├── 3D: 账号目标
    ├── 3E: 内容禁区
    ── 3F: 内容配比（可调节数字）
    │
    ▼
点击"创建 IP 档案"
    │
    ▼
IP 档案创建成功 → 生成周选题池
    │
    ▼
从选题池选择单条 → 生成完整发布包
    │
    ▼
发布归档（历史管理）
```

## 技术实现要点

### 前端
- 响应式设计，暖米色背景 + 棕色主题
- 多标签选择组件（多选 + 自定义补充）
- 数字调节器（带 +/- 按钮）
- 多屏滚动表单，右侧固定说明区

### 后端/AI
- IP 档案知识库持久化（首次录入，后续复用）
- 基于 IP 档案 + 账号目标 → 生成周选题池
- 从选题池 → 生成单条完整发布包（脚本 + 发布文案 + 拍摄建议）
- AI 调用次数计量（每日限额 96 次）

### 数据模型
```
IP 档案 = {
  ip名称, 创始人姓名, 创始人人设特点[], 人设补充,
  行业, 产品服务[],
  目标客户[], 客户补充,
  账号目标[], 目标补充,
  内容禁区[], 禁区补充,
  内容配比: { 流量型, 人设型, 产品型 }
}
```

## 与之前"脚本生成器"的区别

| 维度 | 旧方案（脚本生成器） | 新方案（IP 策划工作台） |
|------|-------------------|----------------------|
| 视角 | 单条脚本 | 账号整体 |
| 输入 | 地域 + 行业 + 话题 | 完整 IP 档案（7 个维度） |
| 输出 | 单条脚本 | 周选题池 → 单条发布包 |
| 核心逻辑 | 一次性生成 | 先建知识库，再持续生成 |
| 内容配比 | 无 | 4:2:1 可调节 |
| 管理 | 无 | IP 档案 + 发布归档 |
