# 广西老板爆款脚本生成器 - 产品需求文档

> 目标：做一个和演示视频一模一样的网站

---

## 产品概述

- **产品名称**：广西老板爆款脚本生成器
- **核心价值**：一键生成适合广西本地老板的短视频脚本
- **技术**：AI 驱动（已投喂广西爆款脚本数据训练）
- **当前阶段**：测试版（Web 网站）
- **下一步**：小程序化，手机端可用

---

## 目标用户

广西本地老板 / 个体户（餐饮、传统行业等）

---

## 核心功能

### 1. 输入区
- **地域选择**：下拉/输入（如"柳州"、"南宁"等）
- **行业身份**：输入（如"螺蛳粉店老板"、"米粉店老板"等）
- **拍摄素材/话题描述**：文本输入（用户描述自己想拍的内容或话题）
- **一键填入测试按钮**：预设测试数据，方便体验

### 2. 一键生成按钮
- 按钮文案："一键生成脚本"
- 生成过程动画：显示"AI正在熬，这条广西脚本..."的加载提示
- 生成时间：约 5 秒

### 3. 输出区（生成结果）
| 模块 | 内容 |
|------|------|
| **完整脚本** | 带情绪和节奏的短视频文案（口语化、有争议性/共鸣点） |
| **发布文案** | 适配平台的发布标题/描述 |
| **拍摄建议** | 镜头、场景、表演指导 |
| **转化引导** | 脚本中包含开店、产品介绍等转化元素 |

---

## 演示案例

### 案例一：螺蛳粉店
- **输入**：柳州 + 螺蛳粉店 + 素材"很多外地人以为口味重，其实..."
- **输出**：争议性脚本，打破外地人刻板印象

### 案例二：狼兵话题
- **输入**：广西狼兵 + 传统行业老板话题
- **输出**：情感向脚本（抗战故事 → 现实创业 → 精神传承）

## 脚本生成 Prompt 思路

```
角色：你是广西本地短视频脚本策划专家
输入：地域 + 行业身份 + 素材/话题
输出：
1. 完整短视频脚本（30-60秒，口语化，有冲突/共鸣/争议点）
2. 发布文案（适配抖音/视频号）
3. 拍摄建议（场景、镜头、表演提示）
4. 转化引导（自然植入产品/服务信息）

风格要求：
- 接地气、口语化
- 开头5秒有钩子/争议
- 中间有情绪铺垫和故事
- 结尾有转化引导（开店、产品等）
- 结合广西地域文化元素
```

## 核心差异点

- 垂直领域：只做广西老板
- 已投喂广西爆款脚本数据训练
- 一键生成，5秒出结果
- 包含脚本 + 发布文案 + 拍摄建议，一站式
- 批量生成能力
