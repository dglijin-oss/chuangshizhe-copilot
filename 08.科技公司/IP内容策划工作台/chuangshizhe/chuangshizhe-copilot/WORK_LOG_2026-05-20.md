## 三、管理员后台微信支付收款码上传功能

### 新增
- `PaymentConfig` 数据库模型（key-value 结构，base64 data URL 存储）
- `GET/PUT /api/admin/payment-config` 接口
- 充值页面创建订单后自动获取并显示收款码

### 调试过程
1. **首次报错"保存收款码失败"** → fetch 缺少 `credentials: "include"`，cookie 未发送，鉴权失败
2. **报错"Unexpected end of JSON input"** → 服务端返回异常响应，客户端 JSON.parse 空响应崩溃
3. **报错"Cannot read properties of undefined (reading 'upsert')"** → 开发服务器缓存了旧版 Prisma 客户端（不含 PaymentConfig 模型）
4. **修复**：`taskkill /F /IM node.exe` 杀进程，重启 `npm run dev`，加载新 Prisma 客户端

### 经验教训
- 新增 Prisma 模型后，必须重启 dev 服务器（Prisma 7.x 客户端缓存机制）
- 所有管理后台 fetch 必须带 `credentials: "include"`
- API 接口容错：客户端先 `res.text()` 再 `JSON.parse()`，避免空响应崩溃

## 四、AI 生成积分不足错误显示修复

### 问题
积分不足时，API 返回 402 `{ "error": "积分不足" }`，但 `withProgress` hook 误判为成功，弹窗显示"运算完成"而非错误信息。

### 原因
`fetch().then(r => r.json())` 的 Promise 是 resolve 的（HTTP 402 不算 reject），`withProgress` 只看 Promise 是否 resolve，不检查响应内容。

### 修复
`withProgress` 解析响应后检查 `error` 字段，有错误时调用 `fail()` 显示红色错误弹窗。
