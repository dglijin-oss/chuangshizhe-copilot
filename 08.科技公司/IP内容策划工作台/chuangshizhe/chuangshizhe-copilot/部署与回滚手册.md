## 一键部署

```bash
bash deploy.sh
```

每次部署会自动生成版本号（如 `v-a77948c-05201430`），旧版本镜像保留在服务器上。

## 一键回滚

```bash
bash rollback.sh
```

回滚会自动找到上一个版本镜像并启动容器，无需手动操作。

## 手动回滚到指定版本

### 1. 查看服务器上所有镜像版本

```bash
ssh root@111.228.45.216 "docker images chuangshizhe-copilot"
```

输出示例：
```
REPOSITORY                TAG             CREATED
chuangshizhe-copilot      v-abc1234-0520   2 hours ago
chuangshizhe-copilot      v-def5678-0519   1 day ago
chuangshizhe-copilot      latest           2 hours ago
```

### 2. 停止当前容器，启动指定版本

```bash
ssh root@111.228.45.216

# 停止并保留当前容器（防止还需要回来排查）
docker stop chuangshizhe-copilot
docker rename chuangshizhe-copilot chuangshizhe-copilot-failed

# 启动指定版本（替换下面的版本号）
docker run -d \
  --name chuangshizhe-copilot \
  --restart always \
  --network host \
  -e DATABASE_URL="postgresql://chuangshizhe_user:Csj2026Secure%21@127.0.0.1:5432/chuangshizhe" \
  -e ALIYUN_API_KEY="sk-sp-1698373d17b74e1bab3d7bccc171f556" \
  -e NODE_ENV=production \
  chuangshizhe-copilot:v-你要的版本号
```

### 3. 验证

```bash
ssh root@111.228.45.216 "docker logs --tail 20 chuangshizhe-copilot"
```

浏览器打开 `http://111.228.45.216:3000` 确认功能。

## 清理旧版本

部署多了以后服务器上会积累很多旧镜像，定期清理：

```bash
ssh root@111.228.45.216

# 查看占用空间
docker system df

# 删除所有已停止的容器（old/failed 容器）
docker container prune -f

# 删除无标签的悬空镜像
docker image prune -f

# 如果要删除某个特定旧版本（保留需要的版本号）
docker rmi chuangshizhe-copilot:v-不需要的版本号
```

## 常用排查命令

```bash

ssh root@111.228.45.216 "docker ps"

# 查看实时日志

# 进入容器调试

# 重启容器（不重新构建）

# 数据库连接测试
ssh root@111.228.45.216 "docker run --rm --network host node:20-alpine sh -c 'apk add --no-cache postgresql-client && psql postgresql://chuangshizhe_user:Csj2026Secure%21@127.0.0.1:5432/chuangshizhe -c \"SELECT 1\"'"
```
