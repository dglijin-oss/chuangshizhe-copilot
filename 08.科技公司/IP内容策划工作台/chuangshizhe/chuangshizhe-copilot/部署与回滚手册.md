# 2026-05-21 服务器部署与调试记录

## 部署环境
- **云服务器**: 京东云 `111.228.45.216`（Ubuntu）
- **面板**: 1Panel
- **数据库**: 本机 PostgreSQL（127.0.0.1:5432，systemd 服务）
- **远程仓库**: `https://github.com/dglijin-oss/chuangshizhe-copilot.git`

## 架构（2026-05-21 更新）

### 双系统合并单容器
- **IP 内容工作台** → 端口 3000
- **启明盒子** → 端口 3001
- 两个 Next.js 应用打包进同一个 Docker 镜像，通过 `start.sh` 同时启动
- 容器使用 `--network host` 模式访问宿主机数据库
- `/home` 为产品选择页，用户登录后选择进入哪个系统

### 登录/注册/退出流程
- 登录/注册成功 → 跳转 `/home` 产品选择页
- 退出登录 → 跳转 `http://localhost:3000/home`
- IP 内容工作台进入按钮 → 新标签页打开

## 调试记录

### 5/20 历史问题（已解决）
1. Prisma generate 输出路径问题 → 移除 prisma.config.ts datasource 配置
2. Zod 环境变量验证 → SKIP_ENV_VALIDATION=1
3. 容器无法连接数据库 → --network host
4. 登录 cookie secure 标志 → 改为 secure: false
5. IP 数据"丢失" → 实为 cookie 问题，非数据问题

## 当前部署流程

```bash
# 1. 提交代码
git add . && git commit -m "修改说明" && git push origin main --force

# 2. 一键部署（打包两个系统）
bash deploy.sh
```

每次部署自动打版本标签（如 `v-a6a4d7a-05211500`），旧镜像保留。

## 回滚

```bash
bash rollback.sh              # 交互式选择版本
bash rollback.sh v-abc123     # 指定版本回滚
```
