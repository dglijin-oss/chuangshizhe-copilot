# SEO优化指南

## SEO基础

### 站内优化

| 项目 | 要求 |
|------|------|
| 标题标签 | 每个页面唯一，包含关键词 |
| Meta描述 | 150-160字符，吸引点击 |
| H标签 | H1唯一，层次分明 |
| URL结构 | 简洁、包含关键词 |
| 图片Alt | 每张图都有描述性alt文本 |

### 内容优化

- 关键词密度2%-5%
- 原创内容优先
- 定期更新内容
- 内链合理布局

### 技术优化

- [ ] 页面加载速度<3秒
- [ ] 移动端适配
- [ ] SSL证书（HTTPS）
- [ ] Sitemap.xml
- [ ] robots.txt配置
- [ ] 结构化数据（Schema）

## SEO交付检查清单

- [ ] TDK（Title/Description/Keywords）配置完整
- [ ] 404页面自定义
- [ ] 301重定向配置
- [ ] 百度/Google站长提交
- [ ] 关键词排名监控设置
