# 官网与商城协同方案

## 品牌官网

### 功能规划
1. **品牌展示**: 公司品牌故事、企业文化
2. **产品展示**: 六堡茶、化橘红、陈皮等产品
3. **直播入口**: 接入直播间/预约
4. **新闻资讯**: 公司动态、行业信息
5. **联系我们**: 联系方式、在线留言

### 技术选型
- 前端: Nuxt.js (SSR，利于SEO)
- 后端: Node.js / Strapi
- 部署: 腾讯云

## 小程序商城

### 功能规划
1. **商品浏览**: 分类展示
2. **在线购买**: 下单支付
3. **会员系统**: 积分、等级、优惠券
4. **订单管理**: 物流查询
5. **直播入口**: 跳转直播间

### 技术选型
- 框架: Uni-app (一套代码，多端部署)
- 后端: Node.js + MySQL
- 支付: 微信支付

## 官网/商城与直播协同

| 渠道 | 引流方向 |
|------|---------|
| 直播间 | → 官网/小程序（留存用户） |
| 官网/小程序 | → 直播间（激活购买） |
| 公众号 | → 官网/直播间 |
| 短视频 | → 官网/小程序/直播间 |
