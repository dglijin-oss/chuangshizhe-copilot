# 工具调用指南

## 什么是工具调用（Function Calling）？

工具调用是让AI智能体能够执行实际操作的能力，比如查询数据库、发送消息、调用API等。

## 工具分类

### 1. 信息类工具
| 工具 | 作用 | 场景 |
|------|------|------|
| 知识库检索 | 从文档中查找信息 | 客服问答、知识查询 |
| 数据库查询 | 查询业务数据 | 订单查询、用户信息 |
| 搜索API | 搜索互联网信息 | 实时信息补充 |

### 2. 操作类工具
| 工具 | 作用 | 场景 |
|------|------|------|
| 发送邮件 | 发送邮件通知 | 工单通知、营销邮件 |
| 创建工单 | 创建客服工单 | 售后服务 |
| 数据写入 | 写入业务数据 | 记录日志、更新状态 |

### 3. 分析类工具
| 工具 | 作用 | 场景 |
|------|------|------|
| 数据分析 | 统计分析 | 报表生成 |
| 图表生成 | 可视化展示 | 数据报告 |
| 代码执行 | 运行代码 | 复杂计算 |

## MCP（Model Context Protocol）

MCP是标准化协议，让AI模型可以调用外部工具。

### 常见MCP工具
- **文件系统**: 读写文件
- **数据库**: 查询、更新
- **HTTP**: 调用REST API
- **浏览器**: 网页操作
- **Git**: 代码管理

## 工具设计规范

### 工具描述模板
```json
{
  "name": "工具名称",
  "description": "工具做什么，在什么场景使用",
  "parameters": {
    "type": "object",
    "properties": {
      "参数名": {
        "type": "string",
        "description": "参数说明"
      }
    },
    "required": ["必填参数"]
  }
}
```

### 设计原则
1. 描述清晰准确，让AI知道何时调用
2. 参数设计合理，必填/选填明确
3. 错误返回信息友好
4. 工具粒度适中
