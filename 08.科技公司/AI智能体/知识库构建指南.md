# 知识库构建指南

## RAG（检索增强生成）原理

```
用户问题 → 向量化 → 知识库检索 → 匹配内容 → 送入LLM → 生成回答
```

## 知识库构建流程

### 第一步：资料收集
- 产品文档
- FAQ
- 操作手册
- 政策制度
- 培训材料

### 第二步：资料处理
1. **格式统一**: 转为Markdown/TXT
2. **分块（Chunk）**:
   - 按段落/标题分块
   - 每块300-500字
   - 保留标题上下文

3. **质量检查**:
   - 删除过时内容
   - 标注矛盾信息
   - 补充缺失信息

### 第三步：向量化存储
| 向量数据库 | 特点 | 适合场景 |
|-----------|------|---------|
| Milvus | 开源、高性能 | 大规模知识库 |
| Chroma | 轻量、易用 | 中小规模 |
| Pinecone | 托管服务 | 快速上线 |
| pgvector | PostgreSQL插件 | 已有PG环境 |

### 第四步：检索优化
1. **混合检索**: 向量 + 关键词
2. **重排序（Re-rank）**: 提高准确率
3. **引用溯源**: 标注答案来源

## 知识库质量评估

| 指标 | 说明 | 目标 |
|------|------|------|
| 召回率 | 找到相关文档的能力 | >90% |
| 准确率 | 答案的正确性 | >85% |
| 响应时间 | 从提问到回答 | <5秒 |
| 覆盖率 | 覆盖的问题范围 | >80% |
