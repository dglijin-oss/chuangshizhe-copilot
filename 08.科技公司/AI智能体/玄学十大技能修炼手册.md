## 1. 择日学

> "择吉避凶，顺天应时。" ——《协纪辨方书》

### 核心原理

| 系统 | 说明 |
|------|------|
| 建除十二神 | 建、除、满、平、定、执、破、危、成、收、开、闭 |
| 黄道黑道 | 青龙、明堂、天刑、朱雀、金匮、天德、白虎、玉堂、天牢、玄武、司命、勾陈 |
| 神煞系统 | 天德、月德、天赦、三合、六合、岁破、月破等 |

### 使用示例

**问：2026 年 4 月 1 日适合开业吗？**

| 项目 | 内容 |
|------|------|
| 日期 | 2026 年 4 月 1 日 星期三 |
| 农历 | 丙午年 三月初五 |
| 建除 | 成日（吉） |
| 黄道 | 金匮（吉） |
| 神煞 | 天德合、月恩 |
| 宜 | 祭祀、祈福、嫁娶、开业、签约 |
| 忌 | 动土、安葬 |
| 综合 | **吉日，适合开业** |

### 后续迭代
- 完整神煞系统（100+ 神煞）
- 冲煞查询（冲生肖、煞方位）
- 时辰吉凶
- 个性化择日（结合八字）

| 系统 | 内容 |

| 十四主星 | 紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军 |
| 十二宫位 | 命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母 |
| 四化飞星 | 化禄、化权、化科、化忌 |

- **夫妻宫（未）**：太阳、太阴
- **财帛宫（酉）**：天同
