# 测试流程

## 测试类型

| 类型 | 说明 | 负责角色 |
|------|------|---------|
| 单元测试 | 单个函数/模块的功能测试 | 开发人员 |
| 集成测试 | 多个模块协作的测试 | 开发人员 |
| 接口测试 | API接口功能测试 | 开发/QA |
| 功能测试 | 完整业务流程测试 | QA |
| 性能测试 | 压力、并发测试 | QA |
| 安全测试 | 漏洞扫描 | 安全工程师 |
| 兼容性测试 | 浏览器/设备兼容 | QA |

## 测试流程

1. **编写测试用例**: 根据需求文档
2. **自测**: 开发人员完成功能后自测
3. **提测**: 提交测试环境
4. **QA测试**: 按测试用例执行
5. **Bug修复**: 开发人员修复
6. **回归测试**: 验证修复后无新问题
7. **验收**: 客户验收测试
