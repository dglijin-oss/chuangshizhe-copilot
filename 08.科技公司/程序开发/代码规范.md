# 代码规范

## 命名规范

### 变量/函数
- 小驼峰：`getUserInfo()`
- 常量全大写：`MAX_COUNT`
- 类名大驼峰：`UserService`

### 文件命名
- 小写+连字符：`user-service.ts`
- 组件大驼峰：`UserCard.vue`

## 代码风格

### 通用规则
- 缩进：2空格或Tab
- 行长度：不超过120字符
- 注释：中英文均可，复杂逻辑必须注释

### 必写注释
- 文件头注释（作者、日期、描述）
- 函数注释（参数、返回值、功能）
- 复杂业务逻辑注释

## 代码Review要点

- [ ] 命名是否清晰
- [ ] 逻辑是否正确
- [ ] 是否有冗余代码
- [ ] 是否有安全隐患
- [ ] 性能是否可优化
- [ ] 是否有测试覆盖

## 安全规范

- 禁止硬编码敏感信息（密码、密钥）
- SQL必须参数化
- 输入必须校验
- 敏感数据必须加密
