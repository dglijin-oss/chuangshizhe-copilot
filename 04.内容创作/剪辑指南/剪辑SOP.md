# 剪辑SOP

## 完整剪辑流程

### 第一步：素材整理
- [ ] 导入素材到电脑/手机
- [ ] 按日期+内容命名文件夹
- [ ] 删除废片（模糊、杂音等）
- [ ] 挑选最佳片段

### 第二步：粗剪
- [ ] 按脚本顺序排列片段
- [ ] 剪掉多余部分
- [ ] 保留核心内容

### 第三步：精剪
- [ ] 添加转场
- [ ] 调整节奏（卡点）
- [ ] 添加BGM
- [ ] 音量平衡

### 第四步：包装
- [ ] 添加字幕
- [ ] 添加标题/花字
- [ ] 添加Logo/水印
- [ ] 添加贴纸/特效

### 第五步：导出
- [ ] 检查画面比例（9:16竖屏或16:9横屏）
- [ ] 检查字幕是否正确
- [ ] 导出高清视频
- [ ] 上传前预览

## 各平台参数

| 平台 | 比例 | 时长建议 | 分辨率 |
|------|------|---------|--------|
| 抖音 | 9:16 | 15-60秒 | 1080x1920 |
| 视频号 | 9:16 | 30-120秒 | 1080x1920 |
| 小红书 | 3:4或9:16 | 30-60秒 | 1080x1440 |
