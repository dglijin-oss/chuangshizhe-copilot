# 拍摄SOP

## 拍摄前准备

### 设备检查
- [ ] 手机/相机充电充足
- [ ] 存储空间足够
- [ ] 三脚架稳定
- [ ] 补光灯调试

### 场景准备
- [ ] 背景整洁
- [ ] 道具到位
- [ ] 产品展示品准备好

## 拍摄参数

### 手机拍摄
| 参数 | 设置 |
|------|------|
| 分辨率 | 1080P或4K |
| 帧率 | 30fps（口播）/ 60fps（慢动作） |
| 比例 | 9:16（竖屏） |

### 灯光设置
- 主灯：正前方45°
- 辅灯：侧面补光
- 背景灯：增加层次感

## 拍摄技巧

### 构图
- 人物居中或偏上三分之一处
- 产品特写填满画面
- 注意水平线

### 运镜
- 推拉：从远到近展示产品
- 摇镜：展示全貌
- 固定：口播、讲解
