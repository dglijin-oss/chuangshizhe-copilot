# 素材命名规范

## 命名原则

1. **日期开头**: 便于按时间排序
2. **描述简洁**: 一眼能看出内容
3. **统一格式**: 全团队统一命名规则

## 命名格式

```
YYYYMMDD_品类_内容描述_版本号
```

### 示例
```
20260512_六堡茶_冲泡过程_v1.mp4
20260512_化橘红_功效介绍_final.mp4
20260512_直播切片_主播A_开场话术.mp4
```

## 版本管理

- v1: 初版
- v2: 修改版
- final: 最终版（已发布）
