# 素材分类规则

## 文件夹结构

```
素材库/
├── 原始素材/
│   ├── 按日期/
│   │   └── YYYY-MM-DD_内容描述/
│   │       ├── 视频/
│   │       ├── 图片/
│   │       └── 音频/
├── 成片/
│   ├── 按平台/
│   │   ├── 抖音/
│   │   ├── 视频号/
│   │   └── 小红书/
├── 直播切片/
│   ├── 按主播/
│   └── 按品类/
└── 素材素材/
    ├── BGM/
    ├── 贴纸/
    └── 转场/
```

## 素材命名规范

### 原始素材
```
日期_品类_镜头描述
例：2026-0512_六堡茶_冲泡过程.mp4
```

### 成片
```
平台_日期_内容简述
例：抖音_20260512_六堡茶冲泡技巧.mp4
```
