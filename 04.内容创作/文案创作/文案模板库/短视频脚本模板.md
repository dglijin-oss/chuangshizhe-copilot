# 短视频脚本模板

## 模板1：产品展示型（30-60秒）

```
[0-3秒] 钩子：痛点/悬念/利益点
  "你有没有发现泡出来的茶总是不好喝？"

[3-10秒] 引入：产品出场
  "其实不是你技术不行，是茶具没选对！"

[10-25秒] 卖点展示
  "今天给大家推荐的这款茶具……"
  （展示产品细节、使用过程）

[25-40秒] 对比/证明
  "你看用普通茶具 vs 用我们的茶具，
  汤色明显不一样！"

[40-55秒] 价格+行动
  "日常价XX，今天直播间只要XX！
  点击下方购物车直接下单！"
```

## 模板2：知识科普型（60-90秒）

```
[0-5秒] 钩子：知识悬念
  "90%的人都不知道，六堡茶这样泡最好喝！"

[5-20秒] 知识点1
  （讲解第一个知识点）

[20-40秒] 知识点2
  （讲解第二个知识点）

[40-55秒] 实操演示
  （现场演示正确方法）

[55-70秒] 总结+引导
  "记住这三点，泡出来的茶好喝十倍！
  关注我，每天学一个茶叶小知识！"
```

## 模板3：日常种草型（15-30秒）

```
[0-5秒] 场景引入
  （日常场景画面）

[5-15秒] 产品+卖点
  （自然展示产品）

[15-25秒] 个人感受
  "我已经喝了三个月了，真的很好……"

[25-30秒] 引导
  （引导看主页/直播）
```
