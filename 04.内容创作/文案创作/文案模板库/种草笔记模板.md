# 种草笔记模板

## 小红书种草笔记模板

### 标题模板
```
类型1：产品推荐型
"XX测评 | 用过XX款茶叶，最好喝的还是它！"

类型2：使用体验型
"喝了3个月的XX茶，忍不住来分享一下"

类型3：对比测评型
"XX vs XX，谁更好喝？真实测评！"

类型4：攻略型
"新手选茶叶指南 | 看这篇就够了"
```

### 正文结构
```
1. 开头（1-2段）：个人背景+为什么推荐
   "作为一个喝了X年茶的人，今天想跟大家分享……"

2. 产品基本信息（2-3段）：产地、品质、特色

3. 使用体验（2-3段）：口感、效果、感受
   （配合图片展示）

4. 优缺点总结
   优点：
   - 
   缺点（真实客观）：
   - 

5. 结尾：购买建议+引导
   "总之，如果你想找一款……强烈推荐试试！
   有问题欢迎评论区问我~"
```

### 图片要求
- 首图：精美封面（产品+文字标题）
- 图2-4：产品细节
- 图5-6：使用场景/效果
- 图7-9：购买截图/评价截图

### 标签建议
```
#茶叶推荐 #好茶分享 #六堡茶 #养生日常
```
