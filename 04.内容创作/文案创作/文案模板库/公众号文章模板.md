# 公众号文章模板

## 文章类型模板

### 模板1：产品介绍文章

```
标题：【新品推荐】产品名称 - 一句话卖点

开头：痛点/故事引入（300字）
  - 描述一个与产品相关的场景或故事
  - 引出产品

正文：
  一、产品简介（200字）
    - 产地、历史、特色

  二、核心卖点（500字）
    - 卖点1 + 图片
    - 卖点2 + 图片
    - 卖点3 + 图片

  三、使用场景（300字）
    - 什么情况下用
    - 怎么用好

  四、用户评价（200字）
    - 真实用户反馈

结尾：
  - 购买引导（小程序/直播链接）
  - 关注引导
```

### 模板2：知识科普文章

```
标题：知识性标题 - 吸引目标读者

开头：
  - 提出问题/制造悬念

正文：
  分3-5个小标题，每部分500-800字
  配图说明

结尾：
  - 总结
  - 互动提问
```

## 排版规范

- 段落不超过5行
- 小标题清晰
- 配图3-8张
- 字体：正文16px，标题18-20px
