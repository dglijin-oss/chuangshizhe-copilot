# 留人话术

## 留人核心逻辑

1. **利益吸引**: 福利预告，让观众有期待
2. **内容吸引**: 有价值的内容让观众想继续看
3. **互动留人**: 让观众参与进来，增加粘性

## 留人话术模板

### 福利预告型
```
刚进来的朋友不要走，接下来这个品才是今天的重头戏！
5分钟后给大家上一个超级福利，比今天任何一的品都划算！
```

### 内容预告型
```
等一下我给大家演示一下怎么鉴别真假XX，学会了再也不怕买到假货！
接下来给大家分享一个泡茶的小技巧，学会了泡出来的茶比外面卖的还好喝！
```

### 抽奖/福袋留人
```
还有3分钟开奖，关注+评论就能参与，大家别走开！
```

### 情感留人
```
进来的朋友都是缘分，多陪我聊一会儿嘛
今天刚开播，大家帮我热热场，待会有更多福利！
```

## 留人技巧

| 技巧 | 说明 | 效果 |
|------|------|------|
| 预告下一波福利 | 给观众一个继续看的理由 | 提高停留时长 |
| 倒计时 | 制造紧迫感 | 提高在线人数 |
| 互动问答 | 让观众有参与感 | 提高互动率 |
| 个人故事 | 增加情感连接 | 提高粘性 |
