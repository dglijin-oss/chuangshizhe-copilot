# 通用话术

```
还没关注的朋友，左上角点一下关注，关注了我们直播间，
每天都能收到我们的开播通知，福利活动第一时间参与！
```

```
觉得我们直播间不错的朋友，帮忙分享一下，让更多的朋友一起来！
```
