# 开场话术

## 通用开场模板

### 模板1：福利预告型
```
欢迎来到XX的直播间！今天给大家准备了超多福利！
开场第一波福利，直接给大家放个大招……
```

### 模板2：产品介绍型
```
大家好！我是XX，专注XX已经X年了！
今天给大家带来的是我们家的爆款产品——XX，
这个产品我已经回购了X次，真的非常好用！
```

### 模板3：互动型
```
进来的朋友们，让我看到你们！
第一次来的扣1，老粉扣2！
今天给大家准备了惊喜，先问大家一个问题……
```

## 不同时段开场话术

| 时段 | 话术要点 | 备注 |
|------|---------|------|
| 早场 | 早上好，养生话题切入 | 针对中老年群体 |
| 午场 | 午休时间轻松聊 | 针对上班族 |
| 晚场 | 晚间福利大放送 | 流量高峰，节奏快 |

## 优秀开场话术收集

> 主播们收集自己或他人效果好的开场话术，在此补充。

- （日期）主播XXX：……
