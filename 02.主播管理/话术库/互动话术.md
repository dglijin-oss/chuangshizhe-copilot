# 互动话术

## 评论互动

### 引导评论
```
觉得这个价格划算的在公屏扣"划算"
想要的扣"想要"
你们觉得多少钱合适，把价格打在公屏上
```

### 回应评论
```
有朋友问……这个问题问得非常好！
XX朋友说……谢谢你的反馈！
我看到有人在问……我来给大家说一下
```

## 停留时长互动

### 停留时长提升
```
进来的朋友别急着走，接下来这个福利才是重头戏
再给大家展示一个非常厉害的东西
```

### 福袋/抽奖互动
```
福袋已经开了，大家参与一下
还有X分钟开奖，关注+评论参与
```

## 节奏把控

### 节奏快时
```
大家不要急，一个一个来，我都会回复的
```

### 节奏慢时
```
来，我出个题考考大家……
有没有朋友用过XX的？说说你的感受
```
