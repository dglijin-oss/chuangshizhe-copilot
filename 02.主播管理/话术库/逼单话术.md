# 逼单话术

## 逼单核心原则

1. **制造紧迫感**: 限时限量
2. **凸显性价比**: 对比原价/市场价
3. **消除顾虑**: 售后保障
4. **促进行动**: 明确告诉观众怎么买

## 逼单话术模板

### 限时限量型
```
这个价格只有今天直播间有！
限量XX份，卖完就没有了！
倒计时5分钟，5分钟后恢复原价！
```

### 对比逼单型
```
日常价XXX，今天直播间只要XXX！
同样的品质，我们直接少了一半！
你随便去比，这个价格绝对没有第二家！
```

### 赠品诱惑型
```
现在下单还送XX！赠品数量有限，送完即止！
买一送一，这个力度只有直播间有！
```

### 保障安心型
```
收到货不满意随时退！我们支持7天无理由！
有任何问题随时找我，售后有保障！
```

## 逼单节奏

| 阶段 | 动作 | 时长 |
|------|------|------|
| 产品讲解 | 详细介绍产品卖点 | 3-5分钟 |
| 价格公布 | 对比原价+公布直播价 | 1分钟 |
| 逼单冲刺 | 限时限量+倒计时 | 2-3分钟 |
| 催单 | 播报已售数量，制造紧迫感 | 1-2分钟 |
