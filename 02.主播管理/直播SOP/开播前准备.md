# 开播前准备

## 开播前检查清单

### 设备检查（开播前30分钟）
- [ ] 手机/摄像头：画面清晰，对焦正常
- [ ] 麦克风：声音清晰，无杂音
- [ ] 灯光：主灯、辅灯、背景灯调试完毕
- [ ] 网络：WiFi连接稳定，测速达标
- [ ] 充电宝/电源：电量充足
- [ ] 手机散热：如有需要，准备散热设备

### 场景布置
- [ ] 背景干净整洁
- [ ] 产品展示架摆放整齐
- [ ] 桌面无杂物
- [ ] 品牌Logo/标语摆放正确

### 产品准备
- [ ] 今日上播产品摆放到位
- [ ] 产品链接已添加到购物车
- [ ] 产品价格设置正确
- [ ] 赠品/试饮装准备就绪

### 直播工具
- [ ] 福袋/抽奖设置完毕
- [ ] 优惠券已配置
- [ ] 贴片/字幕条准备完毕

### 个人准备
- [ ] 妆发完成
- [ ] 服装整洁
- [ ] 话术过一遍
- [ ] 今日目标明确

## 开播前5分钟

1. 最后检查画面和声音
2. 确认产品链接正常
3. 调整状态，保持微笑
4. 深呼吸，准备开播
