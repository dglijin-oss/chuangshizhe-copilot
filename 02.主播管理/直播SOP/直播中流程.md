# 直播中流程

## 直播节奏框架

### 单场直播流程（以3小时为例）

| 时间 | 环节 | 内容 | 备注 |
|------|------|------|------|
| 0-5分钟 | 热场 | 欢迎、关注引导、今日福利预告 | 拉在线人数 |
| 5-15分钟 | 第一个品 | 爆款产品，快速出单 | 拉转化 |
| 15-25分钟 | 第二个品 | 利润产品 | |
| 25-30分钟 | 互动环节 | 福袋/抽奖、互动问答 | 拉停留 |
| 30-60分钟 | 循环上品 | 按品类依次讲解 | 注意节奏 |
| ... | 循环 | 每30分钟一轮循环 | |
| 最后15分钟 | 收尾 | 最后冲刺、感谢、预告下次 | |

### 单品讲解节奏（3-5分钟/品）

1. **引入**（30秒）：痛点引入+产品名称
2. **卖点**（1-2分钟）：3个核心卖点
3. **演示**（1分钟）：现场展示/试吃/试泡
4. **报价**（30秒）：原价vs直播价
5. **逼单**（1-2分钟）：限时限量+倒计时

## 直播间互动管理

### 实时关注数据
- 在线人数变化
- 进人速度
- 转化率
- 停留时长

### 根据数据调整
- 在线下降 → 加强互动/放福利
- 转化低 → 加强逼单话术
- 停留短 → 预告福利/抽奖

### 与运营配合
- 运营在评论区带节奏
- 运营负责上链接、改价
- 运营播报已售数据
- 主播根据运营信号调整

## 突发情况处理

| 情况 | 处理方法 |
|------|---------|
| 卡顿/断线 | 保持镇定，重新开播后道歉+补福利 |
| 价格错误 | 立即下架，道歉+补正确链接 |
| 产品库存不足 | 如实告知+引导关注下一波 |
| 恶意评论 | 无视或拉黑，不要现场争吵 |
