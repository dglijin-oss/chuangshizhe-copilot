# 研学服务标准

> 服务质量标准与要求

---

## 服务原则

1. **安全第一**：所有活动以保障学生安全为最高优先级
2. **教育为本**：活动设计围绕教育目标，寓教于乐
3. **专业执行**：导师团队持证上岗，专业讲解
4. **透明沟通**：及时向学校和家长反馈活动信息

---

## 服务标准

### 行前服务

- [ ] 提交完整报备材料（提前 7 个工作日）
- [ ] 发放致家长信并收集回执
- [ ] 组织行前安全教育
- [ ] 确认所有供应商到位
- [ ] 检查急救物资和保险

### 行中服务

- [ ] 导师配比不低于 1:15
- [ ] 每日向家长推送活动照片/视频
- [ ] 严格执行安全预案
- [ ] 做好用餐、住宿卫生检查
- [ ] 记录学生学习和表现情况

### 行后服务

- [ ] 活动结束 3 日内提交研学报告
- [ ] 收集学生和家长反馈
- [ ] 完成活动复盘
- [ ] 处理报销和结算事宜

---

## 质量评估

| 指标 | 目标值 | 评估方式 |
|------|--------|---------|
| 学生满意度 | ≥ 90% | 问卷调查 |
| 家长满意度 | ≥ 85% | 问卷调查 |
| 学校满意度 | ≥ 90% | 访谈/问卷 |
| 安全事故 | 0 | 记录统计 |
| 投诉率 | ≤ 2% | 投诉记录 |
