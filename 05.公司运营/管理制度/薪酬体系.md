# 薪酬体系

## 薪酬结构

### 主播薪酬
```
总薪酬 = 底薪 + 提成 + 绩效 + 奖金
```

| 项目 | 说明 |
|------|------|
| 底薪 | （根据级别） |
| 提成 | GMV的X% |
| 绩效 | 月度考核评级 |
| 奖金 | 月度/季度/年度 |

### 运营薪酬
```
总薪酬 = 底薪 + 绩效 + 团队提成
```

### 内容薪酬
```
总薪酬 = 底薪 + 绩效 + 爆款奖金
```

## 主播级别与底薪

| 级别 | 要求 | 底薪 |
|------|------|------|
| 实习 | 新人培训中 | |
| 初级 | 独立开播1个月 | |
| 中级 | 月GMV达标 | |
| 高级 | 稳定高产出 | |
| 王牌 | 团队核心 | |
