# 用户画像

## 目标客户分析

### 六堡茶用户

| 维度 | 描述 |
|------|------|
| 年龄段 | 30-60岁为主 |
| 性别 | 男性居多 |
| 地域 | 华南、华东为主 |
| 收入 | 中等以上 |
| 兴趣 | 茶叶、养生、收藏 |
| 消费习惯 | 看重品质和年份 |

### 化橘红用户

| 维度 | 描述 |
|------|------|
| 年龄段 | 25-55岁 |
| 性别 | 女性居多（家庭采购决策者） |
| 地域 | 全国 |
| 消费场景 | 咳嗽、咽喉不适时购买 |

### 陈皮用户

| 维度 | 描述 |
|------|------|
| 年龄段 | 30-65岁 |
| 性别 | 男女皆有 |
| 消费场景 | 日常养生+煲汤调料+收藏 |

## 用户购买路径

1. 刷到短视频/直播 → 产生兴趣
2. 观看直播 → 了解产品
3. 信任主播 → 下单购买
4. 收到产品 → 满意复购/推荐

## 用户痛点

- 不知道如何选茶
- 担心买到假货
- 不确定价格是否合理
- 不知道如何冲泡
