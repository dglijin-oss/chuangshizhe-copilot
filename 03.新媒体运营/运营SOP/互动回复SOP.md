# 互动回复SOP

## 评论回复

### 回复原则
1. **及时**: 发布后30分钟内开始回复
2. **友善**: 语气亲切，避免机械化回复
3. **有价值**: 回复内容能给其他观众参考
4. **引导**: 适度引导关注、下单

### 常见评论回复模板

| 评论类型 | 回复模板 |
|---------|---------|
| 好评 | "谢谢认可！常来直播间有福利哦~" |
| 询价 | "直播间有专属优惠，关注我们不错过！" |
| 产品咨询 | 详细回答+引导看主页/直播间 |
| 负面评论 | 先道歉+引导私信解决 |
| 杠精评论 | 不回复或简单回应，不争论 |

## 私信回复

### 回复时效
- 工作时间内2小时内回复
- 超过时效需致歉

### 常见私信场景
1. **产品咨询**: 详细介绍+引导下单
2. **售后问题**: 安抚情绪+解决问题
3. **合作咨询**: 记录信息+转交负责人
