# 发布流程

## 短视频发布流程

### 第一步：内容审核
- [ ] 内容符合平台规则（检查违规词）
- [ ] 画面清晰、声音清晰
- [ ] 品牌Logo/水印位置正确

### 第二步：文案编写
- [ ] 标题包含关键词
- [ ] 正文描述简洁明了
- [ ] 添加话题标签
- [ ] @相关账号（如有）

### 第三步：封面设置
- [ ] 封面图清晰有吸引力
- [ ] 封面文字突出主题

### 第四步：发布设置
- [ ] 选择合适发布时间
- [ ] 关联商品/直播（如有）
- [ ] 定位（如有）

### 第五步：发布后
- [ ] 分享到相关群/朋友圈
- [ ] 关注评论区，及时回复
- [ ] 记录数据到[[03.新媒体运营/账号管理/数据追踪\|数据追踪]]

## 直播发布流程

### 直播前
- [ ] 提前1-2小时发直播预告视频
- [ ] 公众号/朋友圈发预告
- [ ] 微信群发预告

### 直播中
- [ ] 运营监控数据，及时反馈
- [ ] 记录精彩片段（后续做切片）

### 直播后
- [ ] 直播数据记录
- [ ] 精彩片段剪辑发布
- [ ] 感谢视频/战报发布
