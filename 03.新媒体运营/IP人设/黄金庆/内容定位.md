# 黄金庆-内容定位

## 人设关键词

- **实干支书**: 基层干部身份，真实可信
- **AI先锋**: AI口播第一村创始人，科技助农
- **茶产业带头人**: 1100亩茶园，全产业链
- **朴实农民**: 不包装、不浮夸、接地气

## 内容方向

### 1. 茶园故事（核心内容，占比40%）

**内容类型**:
- 茶园日常：采茶、炒茶、茶园风景
- 茶农故事：带动村民就业的故事
- 产业进展：茶园建设、数字化升级

**情感锚点**:
- 9年坚守，月薪从1万降到1700
- 旧皮鞋6年不舍得穿
- 后备箱砍刀用了6年

### 2. AI助农（差异化内容，占比30%）

**内容类型**:
- AI工具使用教学
- 从不会剪辑到AI一键成片
- 带动全村做口播

**价值输出**:
- "只要识字，就能上手"
- 降低技术门槛，科技普惠

### 3. 六堡茶科普（带货转化，占比20%）

**内容类型**:
- 六堡茶知识科普
- 九松岩品牌故事
- 产品品鉴、冲泡展示

**转化路径**:
- 科普内容 → 直播预告 → 直播卖货

### 4. 乡村生活（增加亲和力，占比10%）

**内容类型**:
- 村民互动
- 乡村日常
- 政策宣讲

## 内容调性

| 维度 | 要求 |
|------|------|
| 语言风格 | 口语化、方言适度、接地气 |
| 情绪基调 | 真诚、质朴、有温度 |
| 视觉风格 | 真实场景、不要过度包装 |
| 节奏 | 不急不躁、娓娓道来 |

## 经典语录（内容锚点）

> "口播带货视频就是新农活，AI工具就是新农具。"

> "只要识字，就能上手。"

> "有人说我'不务正业'，但我只想带大家把农产品卖出去、卖好价。"

> "既然选择了这条路，就别打退堂鼓。"

## 内容禁忌

- ❌ 不要过度商业化，损害公信力
- ❌ 不要脱离真实身份，不要包装人设
- ❌ 不要贬低其他产品/品牌
- ❌ 涉及政策内容要谨慎
