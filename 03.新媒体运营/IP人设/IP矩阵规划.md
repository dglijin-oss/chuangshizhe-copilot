# IP矩阵规划

## 双IP定位

> 两个IP分工明确、互相协同、互相引流，形成品牌矩阵。

## 分工协作

### 内容分工

| 场景 | 黄金庆 | 韦良军 |
|------|--------|--------|
| 茶园/产地 | ✅ 主导 | 🔸 客串/辅助 |
| 专业知识 | 🔸 基础讲解 | ✅ 深度输出 |
| AI/科技 | ✅ 应用展示 | ✅ 技术解读 |
| 直播带货 | ✅ 茶叶为主 | 🔸 知识类产品 |
| 品牌故事 | ✅ 助农故事 | 🔸 专业背书 |

### 引流路径

```
黄金庆（流量型IP）
    │
    ├── 直播引流 → 韦良军（专业内容承接）
    │
    └── 短视频引流 → 韦良军（知识内容沉淀）
```

### 协同场景

1. **直播合作**: 黄支书播产品+韦老师讲知识
2. **短视频联动**: 互相@、合拍
3. **品牌背书**: 韦良军为产品提供专业背书
4. **课程/培训**: 结合两个人设开发内容
