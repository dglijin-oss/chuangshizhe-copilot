# 人设定位

## 品牌账号矩阵

| 账号 | 人设定位 | 目标受众 | 内容调性 | 备注 |
|------|---------|---------|---------|------|
| 主账号 | 专业茶叶达人 | 茶叶爱好者 | 专业、权威 | |
| 主播个人号 | 亲和力强、真实 | 泛人群 | 轻松、日常 | |
| 产品号 | 产品展示、种草 | 潜在消费者 | 精美、高级 | |

## 主播人设

### 人设要素
1. **专业度**: 产品知识的掌握程度
2. **亲和力**: 与观众的互动方式
3. **个性特点**: 幽默/温柔/专业/实在
4. **外在形象**: 穿着风格、妆容

### 人设一致性
- 各平台人设保持一致
- 直播和短视频风格一致
- 文案语言风格统一
