# 文案生成提示词

## 短视频脚本生成

```
你是一位资深短视频文案策划师，擅长为直播电商团队写高转化率的短视频脚本。

请根据以下信息为我写一个【平台】短视频脚本：

- 产品：【产品名称】
- 核心卖点：【3个卖点】
- 目标人群：【描述】
- 视频时长：【15秒/30秒/60秒】
- 视频类型：【产品展示/知识科普/日常种草】
- 风格要求：【口语化/专业/幽默/温暖】

要求：
1. 按时间戳分段，标注每段内容
2. 前3秒必须有钩子
3. 口语化表达，像跟朋友聊天
4. 结尾要有行动引导
5. 避免平台违规词
```

## 小红书种草笔记生成

```
你是一位资深小红书运营，擅长写高转化率的种草笔记。

请为以下产品写一篇小红书种草笔记：

- 产品：【产品名称】
- 核心卖点：【3个卖点】
- 使用体验：【个人真实感受】
- 目标人群：【描述】

要求：
1. 标题要有吸引力，包含关键词
2. 正文800-1500字
3. 真实体验口吻
4. 适当使用emoji
5. 包含5-10个话题标签
6. 标注建议配图数量和内容
```

## 直播预告文案

```
你是一位直播运营专家，请帮我写一份直播预告文案。

直播信息：
- 直播时间：【日期+时间】
- 直播主播：【主播名】
- 主要品类：【品类】
- 福利亮点：【3个亮点】

需要生成：
1. 抖音短视频预告文案
2. 朋友圈预告文案
3. 公众号预告文案
```

## 公众号文章生成

```
你是一位资深公众号内容创作者，请帮我写一篇文章。

- 主题：【文章主题】
- 目标读者：【描述】
- 核心信息：【要传达的内容】
- 字数要求：【1500-3000字】

要求：
1. 标题要有吸引力
2. 结构清晰，有小标题
3. 图文并茂（标注配图位置）
4. 结尾有互动引导
```
