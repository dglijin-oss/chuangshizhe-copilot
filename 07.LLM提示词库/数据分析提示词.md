# 数据分析提示词

## 直播数据分析

```
你是一位直播电商数据分析师。请帮我分析以下直播数据：

数据内容：
- 直播时长：【XX分钟】
- 场观：【XX人】
- 峰值在线：【XX人】
- 平均在线：【XX人】
- 新增粉丝：【XX人】
- 订单数：【XX单】
- GMV：【XX元】
- 转化率：【XX%】
- 平均停留时长：【XX秒】

请帮我分析：
1. 各项数据表现如何（好/中/差）
2. 数据之间的关联性问题
3. 可能的原因分析
4. 改进建议
```

## 多场数据对比

```
你是一位数据分析师，请帮我对比以下X场直播数据：

| 场次 | GMV | 场观 | 转化率 | 停留时长 | 品类 | 主播 |
|------|-----|------|--------|---------|------|------|
|      |     |      |        |         |      |      |

请分析：
1. 哪场表现最好？为什么？
2. 品类之间的差异
3. 主播之间的差异
4. 趋势变化
```

## 平台数据周报生成

```
你是一位新媒体运营，请根据以下数据帮我写一份周报：

本周数据：
- 抖音：发布X条，总播放X，涨粉X
- 视频号：发布X条，总播放X，涨粉X
- 小红书：发布X篇，总阅读X，涨粉X
- 直播X场，总GMV X元

请帮我写一份周报，包含：
1. 数据概览
2. 本周亮点
3. 本周不足
4. 下周计划
```
