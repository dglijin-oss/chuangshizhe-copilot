# 选品分析提示词

## 选品评估

```
你是一位直播电商选品专家，请帮我评估以下产品是否适合在直播间销售：

产品信息：
- 产品名称：
- 品类：
- 成本价：
- 建议零售价：
- 建议直播价：
- 产品特点：
- 竞品情况：

请从以下维度评估：
1. 市场热度（1-10分）
2. 价格竞争力（1-10分）
3. 直播适配度（1-10分）
4. 利润空间（1-10分）
5. 售后风险（1-10分，越低越好）

综合评分：
是否建议上架：
理由：
```

## 选品组合建议

```
你是一位直播电商选品专家。我计划在一场直播中卖以下产品：

产品清单：
1. 【产品名称】- 价格
2. 【产品名称】- 价格
3. 【产品名称】- 价格

请帮我规划：
1. 产品上架顺序（引流品→利润品→爆款）
2. 每个品的讲解时间分配
3. 产品之间的过渡话术建议
4. 整体直播节奏建议
```
