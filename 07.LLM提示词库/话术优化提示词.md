# 话术优化提示词

## 话术优化

```
你是一位直播带货话术专家，擅长分析和优化直播话术。

请帮我优化以下话术：

原始话术：
"（粘贴原始话术）"

产品信息：
- 产品：【名称】
- 目标人群：【描述】
- 平台：【抖音/视频号】

优化要求：
1. 保持口语化
2. 增强吸引力
3. 加入互动元素
4. 避免违规词
5. 提供2-3个优化版本
```

## 话术风格模仿

```
你是一位直播话术专家，请模仿以下风格为我写一段话术：

参考风格：
"（粘贴你喜欢的某段话术）"

要求：
- 产品：【名称】
- 话术类型：【开场/互动/逼单/留人】
- 保持类似风格和节奏
```

## 话术考核评分

```
你是一位直播培训专家，请对以下话术进行评分：

话术内容：
"（粘贴话术）"

评分维度：
1. 吸引力（1-10分）
2. 口语化程度（1-10分）
3. 互动性（1-10分）
4. 转化率潜力（1-10分）
5. 平台合规性（1-10分）

请给出总分和改进建议。
```
