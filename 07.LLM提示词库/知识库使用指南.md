# 知识库使用指南

## 这套知识库怎么用？

### 🎯 核心用途

这套知识库是为你和团队的日常业务设计的 **LLM 辅助工作系统**。核心价值是：

1. **快速查询**: 遇到问题时，快速找到参考答案
2. **AI辅助**: 提供结构化的提示词，让AI高效帮你工作
3. **团队培训**: 新主播入职培训的资料库
4. **SOP沉淀**: 将最佳实践固化成标准流程

---

### 📖 按场景使用

#### 场景1：我要让AI帮我写文案
1. 打开 `[[07.LLM提示词库/文案生成提示词\|文案生成提示词]]`
2. 复制对应模板
3. 填入你的产品信息
4. 发送给AI

#### 场景2：主播要学习产品知识
1. 打开 `[[02.主播管理/培训体系/新人培训SOP\|新人培训SOP]]`
2. 按照培训流程学习
3. 参考各产品的 `[[01.产品中心/六堡茶/产品矩阵\|产品矩阵]]` 文件

#### 场景3：准备一场直播
1. 开播前：看 `[[02.主播管理/直播SOP/开播前准备\|开播前准备]]`
2. 直播中：参考 `[[02.主播管理/直播SOP/直播中流程\|直播中流程]]`
3. 下播后：用 `[[02.主播管理/直播SOP/下播后复盘\|下播后复盘]]`

#### 场景4：分析直播数据
1. 打开 `[[07.LLM提示词库/数据分析提示词\|数据分析提示词]]`
2. 填入你的数据
3. 让AI帮你分析

#### 场景5：选品
1. 参考 `[[01.产品中心/供应链产品/选品标准\|选品标准]]`
2. 用 `[[07.LLM提示词库/选品分析提示词\|选品分析提示词]]` 评估

#### 场景6：开发AI智能体
1. 参考 `[[08.科技公司/AI智能体/智能体开发指南\|智能体开发指南]]`
2. 选择场景方案：`[[08.科技公司/AI智能体/常见场景方案\|场景方案]]`
3. 构建知识库：`[[08.科技公司/AI智能体/知识库构建指南\|知识库构建指南]]`

#### 场景7：为客户做网站方案
1. 查看 `[[08.科技公司/网站开发/网站开发SOP\|网站开发SOP]]`
2. 用 `[[08.科技公司/网站开发/报价模板\|报价模板]]` 出报价
3. 参考 `[[08.科技公司/网站开发/技术选型指南\|技术选型指南]]` 选型

#### 场景8：科技公司售前
1. 查看 `[[08.科技公司/产品与服务/售前方案\|售前方案]]`
2. 参考 `[[08.科技公司/产品与服务/服务清单\|服务清单]]`
3. 用 `[[08.科技公司/协同方案/AI赋能直播\|AI赋能直播]]` 展示协同优势

### 🔄 持续更新

知识库需要持续更新：
- 发现好的话术 → 补充到对应话术库
- 新产品上架 → 更新产品矩阵
- 平台规则变化 → 更新违规词库
- 市场变化 → 更新市场分析
- 新技术/新工具 → 更新技术栈文档
- 新客户案例 → 补充案例库

---

### 🤖 配合AI使用的技巧

1. **提供上下文**: 让AI先阅读相关知识库文件
2. **具体描述**: 产品信息越详细，AI输出越精准
3. **多次迭代**: 不满意可以让AI重写
4. **保存好的输出**: AI输出的好内容可以保存到知识库
