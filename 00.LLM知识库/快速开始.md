# 快速开始

## 三步启用 LLM 知识库

### 1. 添加原始资料

将文章、论文、报告等放入 `sources/` 目录：

```
sources/
├── 文章标题.md        ← 用 Obsidian Web Clipper 或手动粘贴
├── 研究报告.pdf       ← 直接放入
└── 会议纪要.md        ← 会议记录
```

### 2. 告诉 LLM 摄入

对 LLM 说：

> 请处理 `sources/` 中的新资料，按照 `CLAUDE.md` 的规范进行摄入。

LLM 会：
- 阅读资料并提取要点
- 在 `wiki/` 中创建摘要、实体、概念页面
- 更新索引 `wiki/index.md`
- 追加操作日志 `wiki/log.md`

### 3. 提问与探索

向 LLM 提问，它会基于 Wiki 内容回答：

> 帮我总结一下关于 XXX 的所有已知信息。

有价值的回答会被保存为新的 Wiki 页面，知识不断积累。

---

## 定期维护

每周让 LLM 做一次 Wiki 健康检查：

> 请对 Wiki 做一次 lint，检查矛盾、孤立页面和缺失的链接。

---

## Obsidian 推荐设置

| 设置项 | 建议值 |
|--------|--------|
| 附件文件夹 | `sources/attachments` |
| 模板文件夹 | `00.LLM知识库/templates` |
| 日记文件夹 | `00.LLM知识库/daily`（可选） |
| 新笔记默认位置 | `00.LLM知识库/wiki` |
