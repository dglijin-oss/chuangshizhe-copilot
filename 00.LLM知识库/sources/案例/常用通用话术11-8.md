## 一、痛点话术

> 以两句话引出痛点

- 懂得喝化橘红的家人，都是对生活品质要求比较高的，懂得养生、知道善待自己身体的。
- 买过的黄支书家化橘红的老粉都知道。
- 橘红买到好就是宝，买到买不好就是草。
- 买化橘红，一定要买到绿色生产、有机种植有机加工，通过富硒富锗认证、带有国家地理标志的产品、通过官方检验检测过的。
- 不含添加剂，没有高科技狠活、没有农残的才是安全、健康、能够放心喝的化橘红！
- 不要盲目购买散装货，要正规包装的，散货大部分没经过检验检测，建议大家谨慎购买。

**四大担忧**：

| 编号 | 担忧 |
|------|------|
| 1 | 不知道有没有农残 |
| 2 | 卫不卫生 |
| 3 | 喝了会不会不安全 |
| 4 | 喝了不知道有没有用 |

- 我们要提高食品安全意识，要买到正规厂家、正规包装的产品，对自己的健康负责！
- 不怕不懂货，就怕货比货，欢迎买回去对比，买回去看看我们家的品质。
- 买化橘红回去的大部分都是奔着解决问题用的，想要嗓子一天都是润润的！
- 买到不正宗的，会耽误事情浪费时间浪费钱！

## 话术结构速查

| 模块 | 目的 | 关键词 |
|------|------|--------|
| **痛点** | 引发共鸣，制造需求 | 农残、安全、散装、散装货谨慎 |
| **塑品** | 建立信任，展示价值 | 试喝、七天无理由、运费险、3 周年 |
| **场景** | 代入使用场景 | 嗓子润、陈皮搭配、送礼、适用人群 |
| **保障** | 降低决策门槛 | 库存不多、不赚钱、给自己一次机会 |
| **祝福** | 情感连接 | 平安喜乐、春节祝福 |
