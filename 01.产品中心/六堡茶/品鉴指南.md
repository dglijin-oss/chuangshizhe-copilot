# 六堡茶品鉴指南

## 冲泡方法

| 参数 | 建议值 |
|------|--------|
| 水温 | 100°C（沸水） |
| 投茶量 | 5-8g（150ml壶） |
| 浸泡时间 | 第一泡10秒洗茶，之后每泡递增5秒 |
| 冲泡次数 | 8-15泡 |

## 品鉴步骤

### 1. 观外形
- 条索紧结、色泽油润为佳
- 紧压茶注意压制松紧

### 2. 闻香气
- 新茶：陈香、木质香
- 老茶：槟榔香、药香
- 无异味、无霉味

### 3. 看汤色
- 优质六堡茶汤色：红浓明亮
- 劣质茶汤色：浑浊发暗

### 4. 品滋味
- **红**: 汤色红亮
- **浓**: 滋味浓厚
- **陈**: 陈香明显
- **醇**: 口感醇和回甘

## 直播展示建议

- 准备透明玻璃杯展示汤色
- 冲泡过程可以直播展示
- 准备不同年份的茶叶做对比
