# 供应链选品标准

## 选品维度

### 1. 产品品质
- [ ] 产品质量检测报告
- [ ] 食品安全认证
- [ ] 生产日期/保质期
- [ ] 退换货政策

### 2. 价格优势
- [ ] 成本价是否合理
- [ ] 直播价是否有吸引力
- [ ] 同品类竞品价格对比
- [ ] 佣金比例是否达标

### 3. 市场需求
- [ ] 是否有销量数据支撑
- [ ] 平台搜索热度
- [ ] 是否应季产品

### 4. 供应链能力
- [ ] 发货时效
- [ ] 售后服务能力
- [ ] 库存是否充足
- [ ] 物流覆盖范围
